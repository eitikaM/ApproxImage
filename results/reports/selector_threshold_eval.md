1. **Zero Violations by Construction**: Across all thresholds and datasets (1,040 combined task evaluations and 320 holdout task evaluations), violations where the selected mode violates the SSIM threshold are strictly **0**. 2. **Mode 0 / Mode 1 Non-Occurrence**: At SSIM >= 0.99 across all benchmark images, Mode 0 or Mode 1 is **never the true best mode (0 tasks across all effects)**. Mode 2 achieves SSIM >= 0.99 for 100% of tasks where Mode 3 is unsafe, rendering Mode 1 and Mode 0 redundant for threshold 0.99.
