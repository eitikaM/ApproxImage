State of Training Threshold:
The training labels used strictly SSIM >= 0.99. Because the model predicts the probability of violating the 0.99 constraint, its posterior probability P(unsafe) is static with respect to the user's runtime threshold choice. When the user lowers the threshold to 0.98, 0.95, or 0.90 in the UI, the classifier still predicts Mode 3 as "unsafe" because P(unsafe) exceeds the conservative 0.07 cutoff, skipping Mode 3 even when Mode 3 actually satisfies the relaxed threshold.
